# lovedbyagents 제보함

lovedbyagents 사이트에 올릴 제품을 제보하는 저장소입니다. 코드는 여기 없습니다.

1. **New issue → 「제품 제보」**를 고르고 폼을 채웁니다.
2. 운영자가 확인하고 `approved` 라벨을 붙이면 사이트에 올라가고, 이슈에 링크가 달린 뒤 닫힙니다.
3. 올리지 못하면 이슈에 이유가 남습니다. 본문을 고친 뒤 라벨을 다시 붙이면 다시 시도합니다.

에이전트에게 맡기기 좋은 서비스인지 판단하는 신호(MCP 서버, 공개 API, CLI 등)는 폼의 체크리스트를 봐 주세요.
